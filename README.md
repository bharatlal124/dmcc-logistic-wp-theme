# DMCC Logistic WordPress Theme

Custom-coded WordPress theme and homepage for DMCC Logistic Private Limited.
Built from scratch with PHP, HTML, CSS and JavaScript (no page builder).

## Features
- Custom theme files: `header.php`, `footer.php`, `front-page.php`, `functions.php`
- Responsive layout with Bootstrap 5
- Scroll animations with GSAP and ScrollTrigger
- SEO meta tags, Open Graph tags and Organization schema markup
- Sections: Hero, Stats, About, Mission and Vision, Fleet, Industries, Safety, Quality, Contact

## Installation
1. Download this repository as a ZIP (Code > Download ZIP).
2. In WordPress admin, go to Appearance > Themes > Add New > Upload Theme.
3. Upload the ZIP and click Install Now, then Activate.
4. The homepage loads automatically through `front-page.php`.

## Tech Stack
PHP, WordPress, HTML5, CSS3, JavaScript, Bootstrap 5, GSAP
